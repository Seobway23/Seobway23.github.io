# 2026.09.30-01 — JavaScript 글 15개 문체 정리

## 개선

**JavaScript 글 15개의 문체를 기술 문서 톤으로 정리했다.**

- 제목을 명사형으로 바꿨다. 예: "this 바인딩 규칙", "태스크 큐와 setTimeout 실행 시점",
  "프로토타입과 프로토타입 체인". 표지 이미지도 새 제목으로 다시 만들었다.
- 비유 표현을 정확한 용어로 바꿨다. "위에 물어본다"는 `[[Prototype]]` 탐색, "줄 선다"는
  태스크 큐 추가(enqueue), "먹통"은 메인 스레드 블로킹으로 적었다.
- 과장된 문장, 수사 의문문, 굵은 글씨 남용, 대시(—)로 잇는 설명을 걷어냈다.
- 섹션 이름을 문제 상황 / 동작 원리 / 예제 / 자주 하는 실수 / 정리로 맞췄다.

## 수정

- 프로토타입 글의 체인 탐색 다이어그램을 고쳤다. `toString` 이 `Array.prototype` 에
  없는 것처럼 설명하고 있었는데, 실제로는 있다. 예시를 `hasOwnProperty` 로 바꿨다.
- 실행 컨텍스트 글의 다이어그램에서 빈 레인의 토큰을 빼는 단계를 고쳤다.
- 이벤트 루프 관련 글 두 편의 반복 순서를 명세대로 바로잡았다.
  태스크 하나 → 마이크로태스크 전부 → 렌더링 순이다.
