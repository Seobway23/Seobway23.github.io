# 2026.09.30-01 — JavaScript 글 15개 문체 정리

## 개선

**JavaScript 글 15개의 문체를 기술 문서 톤으로 정리했다.**

- 제목을 명사형으로 바꿨다. 예: "this 바인딩 규칙", "태스크 큐와 setTimeout 실행 시점",
  "프로토타입과 프로토타입 체인". 표지 이미지도 새 제목으로 다시 만들었다.
- 비유 표현을 정확한 용어로 바꿨다. "위에 물어본다"는 `[[Prototype]]` 탐색, "줄 선다"는
  태스크 큐 추가(enqueue), "먹통"은 메인 스레드 블로킹으로 적었다.
- 과장된 문장, 수사 의문문, 굵은 글씨 남용, 대시(—)로 잇는 설명을 걷어냈다.
- 섹션 이름을 문제 상황 / 동작 원리 / 예제 / 자주 하는 실수 / 정리로 맞췄다.

## 수정

- 프로토타입 글의 체인 탐색 다이어그램을 고쳤다. `toString` 이 `Array.prototype` 에
  없는 것처럼 설명하고 있었는데, 실제로는 있다. 예시를 `hasOwnProperty` 로 바꿨다.
- 실행 컨텍스트 글의 다이어그램에서 빈 레인의 토큰을 빼는 단계를 고쳤다.
- 이벤트 루프 관련 글 두 편의 반복 순서를 명세대로 바로잡았다.
  태스크 하나 → 마이크로태스크 전부 → 렌더링 순이다.

# 2026.09.30-02 — RAG 검색 구현 글 2편과 실험 원시 데이터

## 기능 확장

**work/rag 카테고리에 설계기준 RAG 글 2편을 추가했다.**

- 「설계기준 RAG의 하이브리드 검색 구현」: dense, BM25, RRF, 리랭커를 코드와 함께 설명하고,
  질의 20개가 단계마다 몇 위였는지 원본 표로 보여 준다.
- 「설계기준 PDF 색인과 수식 기호 검색 실험」: 한글 PDF의 수식 글자(PUA) 복원, 표 추출,
  기호 검색 개선을 가설 9개로 나눠 측정한 결과를 싣는다. 기호 질의 Hit@3 0.033 → 0.833.
- 실험 결과 JSON, 로그, 질의별 순위 CSV를 글에서 바로 내려받을 수 있다.
- 두 글의 전문 용어(BM25, RRF, PUA, 글리프 등 60여 개)를 누르면 설명이 뜬다.

## 개선

- 글 카드 배지가 「Work › RAG」, 「Frontend › JavaScript」처럼 상위와 하위 카테고리를 같이 보여 준다.
- 글 상단에 카테고리 경로가 보이고, 각 단계를 누르면 그 카테고리 글 목록으로 간다.
- 왼쪽 카테고리 목록이 처음부터 펼쳐져 있어 하위 카테고리가 바로 보인다.
- 용어 설명 창의 제목이 내부 이름이 아니라 본문에 쓰인 단어로 나온다.
- RAG 글 두 편을 논문 형식(초록, 배경, 방법, 결과, 논의, 결론, 부록)으로 재구성했다. 목차가 장과 절 두 단계로 나와 원하는 부분으로 바로 갈 수 있다.

- 글에 번호 달린 그림(「그림 1.」)과 캡션이 들어간다. 실험 수치 그래프는 원시 데이터 파일에서 바로 그려져 표와 숫자가 항상 같고, 다크·라이트 테마 색을 따른다.
- RAG 글 두 편에 그림 7개를 추가했다. 질의별 순위 히트맵, 가설 단계별 막대, 처음과 최종 비교, 원문 표 캡처(출처 표기) 등.

## 수정

- 글 상단 표지가 가운데 띠만 보이도록 잘려 왼쪽 아래 주제 배지(JS, RAG 등)가 보이지 않던 문제를 고쳤다. 표지를 원래 비율(1200×630)로 보여 준다.
- 실험 로그 파일을 브라우저에서 열 때 한글과 화살표가 깨지던 문제를 고쳤다.
