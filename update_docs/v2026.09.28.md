# 2026.09.28-01 — JavaScript 로드맵 LV2 완성, 개념 글 4개 추가

## 기능 확장

**로드맵 LV2 에 비어 있던 JavaScript 개념 4개가 채워졌다.** 각각 6~8분 분량이고,
단계별로 재생되는 다이어그램과 직접 고쳐 돌리는 코드가 들어 있다.

| 글 | 답하는 질문 |
|---|---|
| 얕은 복사와 깊은 복사 | 스프레드로 복사했는데 왜 중첩된 값은 원본까지 바뀌는가 |
| TDZ | 바깥에 분명히 있는 변수를 읽었는데 왜 `ReferenceError` 인가 |
| this | 같은 함수인데 왜 어떤 때는 객체, 어떤 때는 `undefined` 인가 |
| 태스크 큐 | `setTimeout(fn, 0)` 이 왜 0ms 뒤에 돌지 않는가 |

이로써 로드맵 **LV0~LV2 가 전부 "작성됨"** 이 됐다(개념 20개 중 13개).
JavaScript 코어 트랙은 12개 중 11개, 남은 건 화살표 함수 하나다.

## 개선

**앞 단계 글에서 다음 글로 바로 넘어갈 수 있다.** 참조 타입 → 얕은/깊은 복사,
호이스팅 → TDZ, 실행 컨텍스트 → this, 이벤트 루프 → 태스크 큐로 본문과
`관련 글` 에 링크를 이었다.

모든 새 글은 MDN · ECMAScript 사양 · HTML 표준만 출처로 쓰고, 출처 38개 전부
실제 응답(200)까지 확인했다.
