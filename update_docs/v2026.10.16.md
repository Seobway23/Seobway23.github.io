# 2026.10.16-02 — JavaScript 로드맵 4·5단계 글 3편, 배포 직후 단계 재생 애니메이션이 원문으로 보이던 문제 수정

## 기능 확장

**로드맵 JavaScript 지도의 4단계와 5단계 개념 3개를 모두 썼다.** JavaScript 지도의 미작성 개념이 없어졌다(코어 12/12, 비동기 5/5, 함수형 3/3).

- 「Promise 의 상태와 then 체인」: pending 에서 fulfilled·rejected 로 한 번만 바뀌는 이유, then 이 새 Promise 를 반환해 값과 오류가 체인을 따라 전달되는 규칙, all·allSettled·race·any 비교.
- 「순수 함수와 부수 효과」: 순수 함수의 두 조건, sort 와 toSorted 처럼 원본을 바꾸는 메서드와 새 배열을 반환하는 메서드 표, React Strict Mode 에서 순수하지 않은 컴포넌트가 #2, #4, #6 을 출력하는 과정.
- 「async/await 와 실행 재개 시점」: 첫 await 까지 동기로 실행되는 범위, 이미 준비된 값을 기다려도 다음 줄이 늦게 실행되는 이유, 순차 await 와 Promise.all 의 시간 차이, forEach 와 async 콜백, return 과 return await 의 차이.
- 각 글에 설명 그림 1장, 단계 재생 애니메이션, 직접 실행하는 예제, 용어 툴팁이 있다. 정의는 ECMAScript 사양과 MDN, React 문서에 근거했고, 예제 출력은 Node 22 에서 실행해 확인한 값이다.
- 선행 글(마이크로태스크, 불변성, 이벤트 루프 글 2편)에서 새 글로 이어지는 링크를 달았다.

## 개선

- 글 안의 그림을 클릭하면 큰 화면으로 열린다. 마우스 휠이나 두 손가락으로 확대하고, 드래그로 옮기고, ESC 나 바깥을 눌러 닫는다. 키보드로는 그림에 초점을 두고 Enter 를 누른다. 모든 글의 그림에 적용된다.

## 수정

- 사이트가 새로 배포된 직후에 글을 열면 단계 재생 애니메이션이 설정 원문(`lane`, `step` 줄)으로 보이던 문제를 고쳤다. 배포 전에 받아 둔 화면 코드가 배포로 지워진 파일을 불러오려다 실패한 것이 원인이다. 이제 그런 경우 페이지를 한 번 자동으로 새로 불러온다.
- 그림, 수식, 애니메이션, 코드 실행 예제 중 하나가 실패해도 나머지는 그대로 표시된다.
