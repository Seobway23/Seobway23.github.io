# 2026.10.15-02 — 스타일링 글 4편 새로 작성

## 기능 확장

**frontend/styling 에 CSS, Sass, Tailwind CSS, shadcn/ui 글을 한 편씩 새로 썼다.** 세 주제를 한 글에 섞어 두었던 기존 「UI & 스타일링 기초」 글은 삭제했다.

- 「CSS 캐스케이드와 명시도」: 선언 하나가 고르는 6단계 비교 순서, 레이어와 명시도 계산 표, 단계별로 재생되는 판정 과정, 직접 고쳐 실행하는 레이어 예제.
- 「Sass 전처리와 SCSS 모듈」: 컴파일 시점에 사라지는 변수, `@use` 모듈, 믹스인과 `@extend`. 모든 SCSS 예제 옆에 실제 컴파일 결과를 나란히 보여 준다.
- 「Tailwind CSS 유틸리티 생성 과정」: 소스 스캔부터 CSS 생성까지의 과정, 조합한 클래스 이름이 동작하지 않는 이유, 브라우저에서 바로 실행하는 예제.
- 「shadcn/ui 컴포넌트 배포 방식과 구조」: 소스를 복사해 넣는 방식, 버튼 파일의 구조(cva, cn, Slot), CSS 변수 테마. 2026년 10월 기준 구성(`cn` 패키지, Radix UI 또는 Base UI)으로 썼다.
- 로드맵에 「스타일링」 트랙이 생겼다. CSS 캐스케이드 → Sass → Tailwind CSS → shadcn/ui 순서다.
- 각 글에 직접 그린 SVG 설명 그림 1장씩, 처음 보는 용어에 툴팁을 넣었다. 예제 출력은 Dart Sass 1.105.1, Tailwind CSS 4.3.3 등 실제 도구로 돌려 확인한 값이다.

## 개선

- 글 표지 왼쪽 아래 배지에 글자 대신 CSS, Sass, Tailwind CSS, shadcn/ui 로고가 들어간다.

## 수정

- 코드 실행 예제에서 직접 쓴 CSS나 Tailwind 클래스가 예제 기본 버튼 스타일에 가려 적용되지 않던 문제를 고쳤다.

# 2026.10.15-03 — 스타일링에 Emotion 글 추가

## 기능 확장

**「Emotion 런타임 CSS-in-JS 동작 방식」 글을 새로 썼다.** 스타일링 트랙은 5편이 되었다(CSS 캐스케이드 → Sass → Tailwind CSS → shadcn/ui → Emotion).

- 컴포넌트가 렌더될 때 스타일이 직렬화, 해시, 캐시 확인, 규칙 삽입을 거쳐 `css-해시` class 가 되는 과정을 그림과 단계 재생 애니메이션으로 보여 준다.
- `css={[base, danger]}` 처럼 합성하면 규칙 하나로 합쳐져 뒤쪽이 이기는 이유를 실제 렌더 결과로 설명한다.
- 슬라이더를 움직이면 값마다 Emotion 규칙이 하나씩 쌓이는 것을 직접 볼 수 있는 실행 예제가 있다. 같은 막대를 `style` 속성으로 그리면 규칙이 늘지 않는다.
- 서버 렌더링 결과, 서버 컴포넌트에서 쓸 수 없는 이유(2026년 10월 Next.js 문서 기준)도 다룬다. 출력 예시는 `@emotion/react` 11.14.0 으로 직접 렌더한 값이다.

## 개선

- 글 표지 배지에 Emotion 로고가 들어간다. 표지 생성기가 이미지 로고도 넣을 수 있게 되었다.

# 2026.10.15-06 — JavaScript 로드맵 3단계 글 4편, 원시 데이터 파일 글자 깨짐 수정

## 기능 확장

**로드맵 JavaScript 지도의 「선행 3단계를 거친다」 줄에 있던 미작성 개념 4개를 모두 썼다.**

- 「화살표 함수의 this 와 일반 함수와의 차이」: 화살표 함수가 this 를 바깥 함수에서 읽는 경로, call·bind 로 바꿀 수 없는 이유, new 로 호출할 수 없는 이유.
- 「고차 함수와 콜백」: map 이 콜백을 (요소, 인덱스, 배열) 로 호출하는 과정, 함수를 반환하는 once·pipe·debounce, `map(parseInt)` 가 `[1, NaN, NaN]` 이 되는 이유.
- 「불변성과 새 값으로 교체하기」: React 에서 배열을 고친 뒤 같은 배열을 넘기면 화면이 안 바뀌는 이유, 바뀐 경로만 새로 만드는 구조적 공유, Object.freeze 가 얕게 적용되는 이유.
- 「마이크로태스크 큐와 실행 시점」: Promise 콜백이 setTimeout 보다 먼저 실행되는 이유, 실행 중 추가된 마이크로태스크도 같은 차례에 실행되는 것, 사용자 클릭과 `click()` 호출에서 리스너 실행 순서가 달라지는 것을 직접 눌러 확인하는 예제.
- 각 글에 설명 그림 1장, 단계 재생 애니메이션, 직접 실행하는 예제, 용어 툴팁이 있다. 정의는 ECMAScript·HTML 표준의 해당 절에 근거했고, 예제 출력은 Node 22 와 브라우저에서 실행해 확인한 값이다.
- 선행 글(this, 클로저, 얕은/깊은 복사, 태스크 큐, 이벤트 루프)에서 새 글로 이어지는 링크를 달았다.

## 수정

- QA 토큰 비용 글 부록의 `token-model.mjs` 를 클릭하면 한글 주석이 깨져 보이던 문제를 고쳤다.
- 이벤트 루프 관련 글 3편에서 비공개 글로 가던 링크(로드맵 인덱스, 런타임 비교, React Query 개요)를 지우고 새 마이크로태스크 글로 바꿨다.
