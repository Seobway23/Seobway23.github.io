# 2026.09.09-01 — 프론트엔드가 최상위 카테고리로, JS 코어 글 5개 추가

## 개선

**카테고리 구조를 바꿨다.** 지금까지는 모든 글이 `study` 안에 들어 있어서
사이드바 첫 칸이 아무 정보도 주지 않았다. 이제 최상위가 이렇게 나뉜다.

```
frontend   29글   ← javascript · react · react-query · threejs · typescript …
study      81글   ← backend · network · infra · ai · electron …
work        2글
```

`frontend` 를 열면 바로 하위 주제가 보이고, 거기서 **리스트 / 로드맵** 을 골라
글 목록으로 볼지 개념 지도로 볼지 정할 수 있다.

기존 `js` 와 `javascript` 로 나뉘어 있던 폴더는 `javascript` 하나로 합쳤다.
글 주소(`/post/slug`)는 바뀌지 않아 기존 링크는 그대로 동작한다.

## 기능 확장

**JavaScript 코어 개념 글 5개가 올라갔다.** 각각 5~8분 분량이고,
단계별로 재생되는 다이어그램과 직접 고쳐 돌리는 코드가 들어 있다.

| 글 | 답하는 질문 |
|---|---|
| 콜 스택 | 함수가 끝난 뒤 어디로 돌아가는지 누가 기억하는가 |
| 원시 타입 | 변수를 복사했는데 왜 어떤 건 같이 안 바뀌는가 |
| 참조 타입 | 복사한 객체를 고쳤는데 왜 원본까지 바뀌는가 |
| 실행 컨텍스트 | 콜 스택에 쌓이는 것은 정확히 무엇인가 |
| 프로토타입 | 만든 적 없는 `toString`·`map` 을 왜 쓸 수 있는가 |

이로써 **JavaScript 코어 트랙이 12개 중 8개** 채워졌다. 로드맵에서 아래 두 단계가
전부 실선(글 있음)으로 바뀌었고, 남은 자리는 점선으로 어디를 더 써야 하는지 보여준다.

모든 글은 MDN과 ECMAScript 사양만 출처로 쓰고 확인 날짜를 함께 적었다.
