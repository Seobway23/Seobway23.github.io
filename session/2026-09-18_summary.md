## GitHub 인증 셋업 (이번에 처음 뚫음)

PR 생성이 막혀 있었고 원인이 3단이었다.

1. `gh` CLI 미설치, MCP GitHub 서버에 토큰 없음
2. MCP 서버가 읽는 변수는 `GITHUB_TOKEN` 이 아니라 **`GITHUB_PERSONAL_ACCESS_TOKEN`**
3. 발급한 fine-grained PAT 에 `pull_requests=write` 없음
   (Repository access 가 `Public repositories` = read-only 라 권한 칸 자체가 안 떴음)

해결: 사용자가 Repository access 를 `Only select repositories` 로 바꾸고
Pull requests / Contents 를 `Read and write` 로 수정 → 즉시 반영.

### 알아둘 것 (다음 세션)

- 실제 로드되는 MCP 설정은 **`~/.claude/plugins/cache/ecc/ecc/1.10.0/.mcp.json`**.
  env 블록이 없어 **부모 프로세스 환경변수를 상속**한다.
  `mcp-configs/mcp-servers.json` 의 `YOUR_GITHUB_PAT_HERE` 는 안 쓰이는 템플릿이다.
- `setx` 는 **이후 새로 뜨는 프로세스**에만 적용 → 이미 떠 있는 MCP 서버는 재시작 전까지 토큰을 못 본다.
  Claude Code 재시작 없이 진행하려면 **PowerShell 툴에서 REST API 직접 호출**이 빠르다
  (PowerShell 툴은 호출마다 새 프로세스라 사용자 환경변수를 바로 읽는다).
- PR 생성 스크립트: 스크래치패드의 `create-pr2.ps1` + `pr-payload.json`.
  한글 본문은 JSON 파일에 쓰고 **바이트 그대로 POST** (셸 인용·PowerShell 5.1 ANSI 인코딩 회피).
